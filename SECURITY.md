# Seguridad

Este repositorio documenta un laboratorio personal de aprendizaje con un firewall FortiGate. No es software ni un servicio en producción, así que no tiene una política formal de versiones soportadas.

## Reportar un problema

Si encuentras en este repositorio alguna credencial, clave, IP pública o cualquier otro dato sensible que se haya filtrado por error, repórtalo abriendo un issue o contactando directamente al autor. Se corregirá y, si aplica, se rotará la credencial afectada.

## Alcance

Las configuraciones, políticas y resultados aquí documentados corresponden a un entorno aislado de laboratorio (VMware, sin usuarios ni datos reales) y **no deben aplicarse tal cual a un entorno de producción**.
